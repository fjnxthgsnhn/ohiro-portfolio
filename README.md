# おおひろ ポートフォリオ

ビルド不要の静的サイトです。`index.html` をブラウザで開けば確認できます。

- `works.js`: プロフィール・作品・X のピックアップ。**中身の編集はここだけ**で済みます
- `thumbs/<動画ID>.jpg`: サムネイル。無い ID は YouTube の標準サムネイルを表示します
- `main.js` / `styles.css`: 表示とデザイン

## 公開

フォルダ一式をそのままアップロードします。

- GitHub Pages: リポジトリに push → Settings → Pages → `main` / root
- Netlify / Cloudflare Pages: フォルダをドラッグ＆ドロップ
